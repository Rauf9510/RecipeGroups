# Recipe Groups

**Recipe Groups** — библиотека для Terraria, добавляющая готовые группы предметов для использования в рецептах.

Мод позволяет разработчикам создавать рецепты, в которых вместо конкретного предмета можно использовать любой предмет из соответствующей группы. Это упрощает создание рецептов и устраняет необходимость дублировать их для альтернативных предметов.

## Возможности

- **Группы предметов:** готовые группы альтернативных предметов для использования в рецептах.
- **Крафтовые станции:** группы столов, верстаков, наковален, раковин и других станций.
- **Мебель:** группы стульев и других предметов мебели.
- **Руды и слитки:** группы руд и слитков с учётом их альтернативных вариантов.
- **Локализация:** поддержка всех языков Terraria для названий групп.
- **Удобство разработки:** возможность использовать готовые группы вместо создания собственных аналогичных решений.

## Использование

Библиотека предназначена в первую очередь для разработчиков модов. Другие моды могут использовать предоставляемые Recipe Groups группы в своих рецептах, позволяя игрокам применять альтернативные предметы без необходимости изменять сам рецепт.

### Пример использования

Чтобы добавить группы предметов в рецепт, используйте метод `AddRecipeGroup()` внутри цепочки создания рецепта.

Например, следующий код создаёт рецепт, для которого нужны железная или свинцовая наковальня и 10 единиц древесины:

```cs
public override void AddRecipes()
{
  CreateRecipe()
    .AddIngredient(ItemID.Wood, 10)
    .AddRecipeGroup("RecipeGroups:IronAnvils")
    .Register();
}
```

В этом примере:

- `AddIngredient()` добавляет 10 единиц древесины в качестве обычного ингредиента.
- `AddRecipeGroup()` добавляет группу железных наковален, позволяя использовать любой предмет, входящий в эту группу.
- `Register()` завершает создание и регистрирует рецепт.

Таким образом, для выполнения рецепта потребуется 10 единиц древесины и одна из подходящих наковален из группы `RecipeGroups:IronAnvils` (железная или свинцовая наковальня).

### Другие примеры групп

```cs
.AddRecipeGroup("RecipeGroups:Chairs")
.AddRecipeGroup("RecipeGroups:Workbenches")
.AddRecipeGroup("RecipeGroups:CopperBars")
.AddRecipeGroup("RecipeGroups:IronOres")
.AddRecipeGroup("RecipeGroups:Sinks")
```

Полный список доступных групп можно найти в исходном коде библиотеки Recipe Groups.

## Примечание
Terraria уже содержит некоторые встроенные группы предметов, например `IronBar` и `Wood`. Recipe Groups дополняет их собственными группами, которых нет среди стандартных.

## Совместимость

Recipe Groups разработана для Bunny-Loader и предназначена для использования другими модами в качестве библиотеки.
